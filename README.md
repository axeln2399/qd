# qd

**→ [axeln2399.github.io/qd](https://axeln2399.github.io/qd/)**

A 24-month plan to go from physics graduate + five years of JVM engineering to a hireable **quant developer**, studying one hour on weekday evenings and two to three at the weekend.

The plan lives on the site, not in this README — it has a week-by-week tracker that saves progress on your device, and it installs to a phone home screen. Add to Home Screen on iOS, Install on Android.

- **[The plan](https://axeln2399.github.io/qd/)** — seven phases, 104 weeks, gates, rules, materials
- **[Week 0 diagnostic](https://axeln2399.github.io/qd/diagnostic.html)** — 20-point closed-book maths test; sit it before week 1
- **[LOG.md](LOG.md)** — the weekly log, committed every Sunday without exception

## The shape of it

| | |
|---|---|
| Role | Quant developer |
| Specialisation | Market microstructure & execution |
| Language | Full C++ pivot, with a planned off-ramp at week 34 |
| Market | Equities / traditional finance; crypto as a data source only |
| Flagship | C++ limit order book, then a live feed handler, then an exchange simulator |
| Exit criteria | γ markets fluency (wk 26) · β shipped project (wk 68) · α passing screens (wk 104) |

## Files

`index.html` and `diagnostic.html` are the site. `style.css` is shared. `sw.js` and `manifest.webmanifest` make it installable and work offline. `.nojekyll` keeps GitHub Pages from processing any of it.
